# Rithik Chauhan — VAPT & Offensive Security Portfolio

## Package contents
- `index.html` — portfolio with five interactive assessment environments, animated entry flow, project cards and credentials.
- `assets/certifications/` — supplied certification PDFs and image copies.
- `assets/favicon.svg` — supplied favicon.
- `reference-source/` — original uploaded site source retained for reference.

## Featured projects
- **ReconForge** — reconnaissance workflow and reporting project.
- **Clickjacking PoC Lab** — [Open live lab](https://rk11-ops.github.io/clickjacking-poc-lab/). A controlled web-security lab focused on UI redressing, frame protections and reproducible PoC observations. Use only against systems you own or are explicitly authorized to test.
- **PentestingEverything** — security knowledge base covering methodologies, tools and references.

## Visual direction
The portfolio uses a restrained offensive-security / red-team operations aesthetic: dark tactical surfaces, red accent, telemetry labels, architecture diagrams and system toolchains. The Clickjacking lab card includes a direct external launch link.

## Deployment
Deploy the package root to GitHub Pages or another static host. The main portfolio is self-contained; `reference-source/` is retained for reference and is not loaded by the main page.

## Privacy
The supplied archive contained certification documents and images. No login passwords, API keys or SSH private keys were identified in the source archive. Keep private documents and secrets out of public repositories, and publish certificates only if you are comfortable sharing them.
